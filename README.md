# Rume Gabari — Portfolio Website

Personal portfolio website for Gabari Rume Mamuromu, a Computer Science undergraduate and founder of O’VerSol.

## Current status

This is an earlier version of my portfolio and is due for a content and design refresh. The website is not being presented as a final or fully up-to-date account of my current experience.

## Built with

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the local development server
- `npm run build` — type-check and build for production
- `npm run lint` — run ESLint
- `npm run preview` — preview the production build

## Planned refresh

The next iteration will update the project selection, biography, experience, skills and visual presentation to reflect my current work more accurately.
